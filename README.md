1. Akses / buka tautan Google colab
2. membuka notebook baru, klik + Code lalu tempelkan seluruh skrip Python simulator inkubator ke dalam sel
3. Hubungkan ke Runtime Cloud: Klik tombol Connect (Hubungkan) di pojok kanan atas layar dan tunggu beberapa detik hingga indikator status RAM dan Disk muncul
4. Sesuaikan Nilai Input Pengujian: Pada bagian konfigurasi atas di dalam sel kode, ubah nilai variabel INPUT_SUHU (contoh: 36.8) dan INPUT_KELEMBABAN (contoh: 42.0) sesuai kondisi ruang inkubator yang ingin disimulasikan.
5. jalankan Program (Run): Klik tombol ikon Play (▶) di sebelah kiri atas sel kode
6. Lihat Hasil Keluaran & Grafik: Setelah proses eksekusi selesai, area output tepat di bawah sel kode akan menampilkan hasil cetak terminal (derajat keanggotaan aturan aktif, serta status akhir Blower dan Kipas) beserta grafik visualisasi empat panel (2x2).
